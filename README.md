# Partify

A specialized feature implementation built for a Shopify ecosystem as part of a technical coding challenge during a software engineering recruitment process. 

[![Live Demo Button](https://img.shields.io/badge/Live_Demo-Partify-blue?style=for-the-badge)](https://chrisljewell.github.io/PartifyCode/) | 📂 **[View Source Code](https://github.com/ChrisLJewell/PartifyCode)**

---

## 🎯 About This Project
This project was developed as a technical coding assessment for Partify. The goal was to build a dynamic, adaptable vehicle search form that allows customers to filter by **Year, Make, Model, and Product Type**, automatically navigating them to the matching Shopify collection page.

---

## ✨ Features

* **Dynamic Cascading Logic:** Dropdowns update sequentially to ensure valid catalog selections.
* **Shopify URL Handling:** Converts vehicle parameters into standardized Shopify collection handles.
* **Product Type Filtering:** Correctly encodes product types as query parameters.
* **Adaptable & Scalable Architecture:** Designed to seamlessly scale from a small test dataset to large catalog structures.
* **Responsive UI/UX:** Clean, accessible frontend built using vanilla HTML, CSS, and JavaScript.

---

## 🚀 How It Works

1. **Select Year:** Populates available vehicle makes for the selected model year.
2. **Select Make & Model:** Narrow down to the exact vehicle.
3. **Select Product Type (Optional):** Applies additional product filters to the collection view.
4. **Search Catalog:** Redirects directly to the structured URL on the Partify store.
